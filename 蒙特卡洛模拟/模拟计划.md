# 永久组合变体 × 34年蒙特卡洛模拟计划

## 目标

模拟从26岁到60岁（2026-2060年），通过渐进加码定投永久组合变体，评估1000万资产的实现概率。

## 资产配置（取区间中值）

| 资产            | 范围     | 模拟权重    | 数据来源                              |
| ------------- |:------:|:-------:| --------------------------------- |
| 红利低波          | 25-35% | **30%** | data/processed/cn_H30269_CSI.csv  |
| 美股QDII（标普500） | 25-35% | **30%** | data/processed/us_sp500_daily.csv |
| 资源能源          | 15-25% | **20%** | MySQL sector_daily（有色金属+煤炭+石油石化）  |
| 黄金（沪金）        | 8-15%  | **12%** | data/processed/cn_H30269_CSI.csv  |
| 债券+现金         | 5-15%  | **8%**  | 固定利率（债券3%+现金2%）                   |

## 定投方案

渐进加码：

- 第1年：2000元/月
- 第2年：2500元/月
- 第3年：3000元/月
- 第4年：3500元/月
- 第5年起：4000元/月封顶

## 三组场景

| 场景  | 均值调整        | 含义               |
|:---:|:-----------:| ---------------- |
| 保守  | 历史均值 - 0.5σ | 利率低迷+美股估值回归+增长放缓 |
| 中位  | 历史均值        | 延续过去20年模式        |
| 乐观  | 历史均值 + 0.5σ | 经济持续增长+资产溢价维持    |

## 模拟参数

- 模拟次数：100,000次/场景
- 时间跨度：34年（408个月）
- 收益分布：多元正态分布（基于历史协方差矩阵）
- 再平衡：每月定投时自动再平衡至目标权重
- 交易成本：忽略（定投+长期持有模式）

## 输出内容

1. 各年龄（26-60岁）的资产分位数表（5%/25%/50%/75%/95%）
2. 资产终值分布直方图
3. 年龄-资产曲线图（含概率区间）
4. 1000万达成概率汇总
5. 分析报告
